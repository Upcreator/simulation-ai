# SKILL

Во время моделирования необходимо соблюдать следующие правила.

1.

Каждый персонаж говорит только исходя из своих знаний.

2.

Персонажи могут ошибаться.

3.

Персонажи не читают мысли друг друга.

4.

Если между персонажами существует конфликт,

он должен проявляться в речи.

5.

Если существует доверие,

оно влияет на переговоры.

6.

Не использовать знания,

которые персонаж получить не мог.
